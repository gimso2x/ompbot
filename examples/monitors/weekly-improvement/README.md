# 주간 개선 회의 회의록 형식

`meeting.py`가 검사·기록하는 회의록 형식이다. 설치 방법은 저장소 README의 모니터 절을 본다.

회의록 경로: `~/.ompbot/workspace/meetings/<YYYY>-W<ww>.md`(ISO 주차, KST). 형식:

```
# 주간 개선 회의 2026-W45
기간: 2026-11-02 ~ 2026-11-08 (KST)
제안자: anthropic/claude-opus-5-5 · 검토자: google-antigravity/gemini-4-argon

## 안건
| ID | 제목 | 근거 | 제안 | 검토 | 결정 | TASK |
|---|---|---|---|---|---|---|
| P-2026W45-1 | … | … (자체회고 2026-11-02) | … | 동의: … | 대기 | - |
```

## `meeting.py check <file>` — 형식 게이트

통과 exit 0, 위반 exit 2 + stderr에 위반마다 한 줄(줄 번호 포함):

- 제목 줄 `# 주간 개선 회의 \d{4}-W\d{2}`, `기간:`, `제안자:` 줄, `## 안건` 표가 있다. 안건 0개는 `안건 없음` 한 줄로 대신할 수 있다.
- 안건 행 1~5개, 열 7개, 셀 안 `|` 금지.
- ID `P-<YYYY>W<ww>-<1..5>`, 주차가 제목과 같고 행 안에서 중복 없음.
- 근거 셀에 출처 태그 1개 이상: `\((자체회고 \d{4}-\d{2}-\d{2}|모니터 [^)]+|TASK T-\d{8}-\d{2}|로그 event=[a-z_]+|회의 \d{4}-W\d{2})\)`.
- 검토 셀은 `동의:`·`수정:`·`반대:`·`검토 실패:` 중 하나로 시작.
- 결정 셀 ∈ `대기|채택|기각|보류`, TASK 셀은 `-` 또는 `T-\d{8}-\d{2}`.

## `meeting.py decide <file> <ID>=<채택|기각|보류> … [--task <ID>=<T-…>]…` — 결정 기록

- 전이는 `대기|보류 → 채택|기각|보류`만. 채택된 안건은 `--task`로 TASK 셀만 채울 수 있다(결정 인자 없이 `--task`만 주는 호출 허용). 그 밖의 전이, 모르는 ID, 쓰고 난 결과가 `check`를 통과하지 못하는 경우는 exit 2이고 파일은 바뀌지 않는다.
- 쓰기는 같은 디렉터리 임시 파일 + `os.replace`. 성공 시 stdout에 바뀐 행 수.
